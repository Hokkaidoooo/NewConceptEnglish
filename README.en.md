# New Concept English study notes

[简体中文](README.md) · English · [Español](README.es.md) · [日本語](README.ja.md)

An independent guide to the study archive forked from [andylee1890/NewConceptEnglish](https://github.com/andylee1890/NewConceptEnglish). The archive has resources for Books 2–4. Use an authorized copy of the book and audio for the lessons themselves.

## Find your book

Open a folder or lesson index on GitHub to see what is available. No installation is needed to browse. Use a PDF reader or a word processor for the corresponding files. The notes and indexes are primarily in Chinese.

| Book | How to use the archive |
| --- | --- |
| [Book 2](NCE2/) | Browse the PDF and text notes. After reading, try retelling a short passage in chronological order. |
| [Book 3 index](NCE3/README.md) · [files](NCE3/) | Find notes by lesson number and practice summarizing paragraphs or paraphrasing sentences. |
| [Book 4 index](NCE4/README.md) · [files](NCE4/) | Find notes by lesson number and practice separating the author's main claim from the supporting evidence. |

Try listening or reading once, recalling the key points without looking, then using the notes to see what you missed. Share study tips in the [upstream Discussions](https://github.com/andylee1890/NewConceptEnglish/discussions).
