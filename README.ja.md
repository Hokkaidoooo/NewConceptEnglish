# New Concept English 学習ノート

[简体中文](README.md) · [English](README.en.md) · [Español](README.es.md) · 日本語

[andylee1890/NewConceptEnglish](https://github.com/andylee1890/NewConceptEnglish) をフォークした、第 2〜4 冊の学習資料を探すための非公式ガイドです。レッスンには正規の教科書や利用を許諾された音声教材を使ってください。

## 冊別の入口

GitHub でフォルダーやレッスン索引を開くと、収録ファイルを確認できます。閲覧のために本プロジェクトをインストールする必要はありません。PDF や Word 文書を開く場合は、対応するビューアーを使ってください。索引とノートの多くは中国語です。

| 冊 | 使い方 |
| --- | --- |
| [第 2 冊](NCE2/) | PDF やテキストのノートを参照し、短い文章の内容を時系列で話し直します。 |
| [第 3 冊の索引](NCE3/README.md) · [ファイル一覧](NCE3/) | レッスン番号でノートを探し、段落の要約や文の言い換えを練習します。 |
| [第 4 冊の索引](NCE4/README.md) · [ファイル一覧](NCE4/) | レッスン番号でノートを探し、筆者の主張とそれを支える根拠を整理します。 |

一度読んだり聞いたりした後、原文を見ずに要点を思い出し、ノートで抜けを確認します。学習方法の情報交換には[フォーク元の Discussions](https://github.com/andylee1890/NewConceptEnglish/discussions)を利用できます。本リポジトリには [GPL v3 のライセンス文書](LICENSE.txt)がありますが、第三者の教科書、翻訳、音声、動画、練習問題の再配布が許可されているとは限りません。各資料の利用条件を確認してください。
