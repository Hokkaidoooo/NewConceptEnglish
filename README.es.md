# Apuntes de New Concept English

[简体中文](README.md) · [English](README.en.md) · Español · [日本語](README.ja.md)

Guía independiente del archivo de estudio derivado de [andylee1890/NewConceptEnglish](https://github.com/andylee1890/NewConceptEnglish). Hay recursos para los libros 2 a 4. Para seguir las lecciones, utiliza una copia autorizada del libro y del audio.

## Cómo encontrar los apuntes

Abre una carpeta o el índice de lecciones en GitHub para ver los archivos disponibles. No hace falta instalar el proyecto; para abrir un PDF o un documento de Word puedes usar el lector correspondiente. Los índices y la mayoría de los apuntes están en chino.

| Libro | Qué practicar |
| --- | --- |
| [Libro 2](NCE2/) | Consulta los apuntes en PDF o texto y vuelve a contar un pasaje breve por orden cronológico. |
| [Índice del libro 3](NCE3/README.md) · [archivos](NCE3/) | Busca los apuntes por número de lección y practica el resumen de párrafos y la reformulación de frases. |
| [Índice del libro 4](NCE4/README.md) · [archivos](NCE4/) | Busca los apuntes por número de lección y distingue la tesis del autor de los argumentos que la respaldan. |

Después de escuchar o leer una vez, recuerda las ideas clave sin mirar el original y contrástalas con los apuntes. Puedes compartir técnicas de estudio en el [foro del proyecto original](https://github.com/andylee1890/NewConceptEnglish/discussions).
